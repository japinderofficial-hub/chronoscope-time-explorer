# 🕰️ ChronoScope – Time Travel & Global Explorer

## 📌 Project Overview
ChronoScope is an interactive web application that allows users to explore the world across different time periods and locations. Users can select a specific year and country to discover historical events, news, entertainment trends, and real-world insights.

The application simulates a **time-travel experience**, enabling users to understand how the world evolved across different years and regions.

---

## 🎯 Objective
The objective of this project is to build a web application that demonstrates:
- JavaScript fundamentals  
- API integration using Fetch API  
- Use of Array Higher-Order Functions (HOFs)  
- Responsive and user-friendly UI design  

---

## 🌐 APIs Used
The application integrates multiple public APIs to fetch dynamic data:

- **Wikipedia API** – for historical events and information  
- **TMDb API** – for movies and entertainment data  
- **GNews API** – for news articles  
- **Open-Meteo API** – for weather data  
- **Quotable API** – for inspirational and contextual quotes  

---

## ✨ Features (Planned)

### 🔍 Core Features
- Select a **year** to explore past data  
- Select a **country** to localize results  
- Display:
  - 📜 Historical events  
  - 📰 News headlines  
  - 🎬 Popular movies  
  - 🌦️ Weather information  

### ⚙️ Functional Features
- Search functionality for dynamic content  
- Filtering results using Array HOFs  
- Sorting data (e.g., date, popularity)

### 🎨 UI/UX Features
- Responsive design (mobile, tablet, desktop)  
- Dark mode / Light mode toggle
